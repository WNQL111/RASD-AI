# RASD AI — Datasets & Evaluation Benchmarks

## 1. Overview
Contains reference video datasets and evaluation test cases used to validate detection accuracy, suppression heuristics, and false alarm rejection.

## 2. Test Categories
- **Violence Benchmarks**: Physical assault, striking, and fighting clips used to verify proximity and motion opposition logic.
- **Traffic Collision Benchmarks**: Vehicle-vehicle crashes and pedestrian collision footage validating deceleration spikes and IoU overlap.
- **Benign Control Videos**: Mall walking, normal pedestrian gatherings, and parking lot motion validating benign crowd suppression.
