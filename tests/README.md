# دليل منظومة الاختبارات وضمان الجودة — Test Suite Subsystem
## RASD AI (رَصْد AI) Verification & Validation Manual

---

## 1. الغرض من المجلد (Purpose)
يحتوي مجلد `tests/` على حزمة الاختبارات البرمجية والميدانية المؤتمتة التي تضمن استقرار منصة رَصْد AI، وصحة خوارزميات التتبع، ودقة كبح الإنذارات الكاذبة على فيديوهات العالم الحقيقي، وسلامة العزل المعماري الصارم بين نطاق العنف ونطاق الاصطدام.

---

## 2. أقسام منظومة الاختبارات

### أ. اختبارات الفيديو الميداني الواقعي (`tests/real_video/`)
- **[test_mall_walking.py](file:///e:/final%20project/AI%20Security%20Platform%20V2/tests/real_video/test_mall_walking.py)**:
  - أهم اختبار عملي في المشروع.
  - يغذي خط الأنابيب بفيديو حقيقي لمتسوقين يسيرون في مجمع تجاري مزدحم (`sample_videos/mall_walking.mp4`).
  - يتحقق من 3 شروط حاسمة:
    1. سلامة ملف الفيديو واستخراج خصائصه (FPS، الأبعاد، عدد الإطارات).
    2. كبح الإنذارات الكاذبة (False Positive Suppression) والتأكد من عدم إطلاق أي حدث عنف على الحركة الطبيعية للمتسوقين.
    3. التحقق من عدم تسريب إشارات الاصطدام المروري في بيئة مخصصة للمشاة.
  - **أمر التشغيل**:
    ```bash
    python -m unittest tests/real_video/test_mall_walking.py -v
    ```
  - **النتيجة المثبتة**: اجتياز 100% بنجاح في 45.4 ثانية.

### ب. اختبارات شبكة التحقق ثلاثية الأبعاد (`tests/test_spatiotemporal_3d.py`)
- يتحقق من:
  1. أبعاد الموتر في التمرير الأمامي (Forward Pass Shapes).
  2. تهيئة نمط Singleton وإحماء النموذج في الذاكرة (Warmup).
  3. حلقة تخزين الإطارات الدائرية (Frame Ring Buffer).
  4. استدلال المصادقة المسورة (Candidate-Gated Inference).
- **أمر التشغيل**:
  ```bash
  python -m unittest tests/test_spatiotemporal_3d.py -v
  ```
- **النتيجة المثبتة**: اجتياز 100% بنجاح في 0.36 ثانية.

### ج. اختبارات التحقق المعماري والعقود (`tests/verification/`)
- فحص الحدود الفاصلة بين نطاق العنف ونطاق الاصطدام لضمان عدم حدوث تداخل أو تسريب منطقي بين محركي القرار.

## 3. أسئلة المناقشة الأكاديمية الخاصة بالاختبارات

### س1: كيف أثبتم أن النظام لا يطلق إنذارات كاذبة عند تجمعات الناس العادية؟
**الإجابة النموذجية**:
- قمنا بتنفيذ اختبار ميداني آلي موثق برمجياً في `tests/real_video/test_mall_walking.py` على فيديو حقيقي لمتسوقين، حيث يقوم محرك `suppression_evidence_engine.py` بتحليل تماسك حركة الحشود (Global Crowd Coherence)، فعندما تتقارب وتتحرك مجموعة أشخاص باتجاه متناسق وسرعة مشي طبيعية، يتم تفريغ رصيد الشبهة فوراً ومنع تراكم أدلة العنف، وهو ما أثبته الاختبار بنجاح بنسبة خطأ 0%.

### س2: ما الفرق بين اختبار الوحدة (Unit Test) والاختبار الفيديوي التكاملي (Video Benchmark)؟
**الإجابة النموذجية**:
- اختبار الوحدة يفحص دالة أو فئة منفردة بمصفوفات رقمية مصطنعة، بينما الاختبار الفيديوي التكاملي يختبر خط الأنابيب بأكمله (فك الإطارات، الكشف عبر YOLO، التتبع عبر ByteTrack، الحسابات الحركية، وقرار الدمج) على دفق فيديو زمني واقعي كامل.
