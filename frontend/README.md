# دليل الواجهة الأمامية وغرفة العمليات — Frontend SOC Subsystem
## RASD AI (رَصْد AI) Security Operations Center Frontend Manual

---

## 1. الغرض من المجلد (Purpose)
يمثل مجلد `frontend/` واجهة المستخدم الرسومية لغرفة العمليات الأمنية (Security Operations Center - SOC). تم بناء هذه الواجهة بنظام تطبيق الصفحة الواحدة (Single Page Application - SPA) باستخدام أحدث إصدارات **React 19** وأداة الحزم فائقة السرعة **Vite 8** وإطار التنسيق الحديث **TailwindCSS 4**. تم تصميم الواجهة بنظام الهوية الرسمية المعتمدة للمنصة: **Dark Security Intelligence Theme** لتقليل الإجهاد البصري للمشغلين وتوفير أعلى درجات التباين والوضوح في مراقبة الفيديوهات والإنذارات.

---

## 2. الوظيفة التي تؤديها داخل المشروع
- **المراقبة الميدانية المباشرة (Live Surveillance Matrix)**: عرض مصفوفة الكاميرات المتعددة (Grid، Quad، Focus) مع البث اللحظي.
- **استقبال التنبيهات الفورية (SSE Alert Stream)**: استقبال إشعارات الحوادث الحرجة عبر Server-Sent Events وإطلاق نغمات الإنذار الصوتي اللحظي.
- **إعادة التشغيل الجنائي اللحظي (3D Forensic Replay)**: فحص الفيديو بالثانية، القفز السلس عبر الزمن، وعرض شجرة الأسباب والقرارات المفسرة (Explainable AI Tree).
- **إدارة القضايا والملفات الجنائية (Cases Management)**: إنشاء ملفات التحقيق القضائي وربط الأحداث والأدلة بسلسلة الحيازة (Chain of Custody).
- **سجل الأحداث والتصفية المتقدمة (Audit Events Table)**: تصفية وفرز السجلات الأمنية وتصديرها بصيغة CSV رسمية.
- **التحكم بعتبات الذكاء الاصطناعي (Settings)**: تعديل مسافات التقارب وسرعات الاشتباه ونسب الحساسية مباشرة من الواجهة.
- **دعم ثنائية اللغة (Bilingual Support)**: التبديل الفوري بين **العربية (RTL)** و **الإنجليزية (LTR)** دون إعادة تحميل الصفحة.

```
frontend/
├── package.json                # التبعيات (React 19, TailwindCSS 4, Lucide React, Axios...)

    ├── main.jsx                # نقطة الانطلاق وتركيب React في عنصر root
    ├── App.jsx                 # شجرة مسارات التنقل (React Router v7)

    │   ├── Layout.jsx          # الهيكل العام، الشريط الجانبي (Sidebar)، والملاحة
    │   └── RasdLogo.jsx        # الشعار الهندسي الرقمي لرَصْد AI
    ├── context/
    │   └── LanguageContext.jsx # سياق الترجمة والتبديل بين العربية والإنجليزية واتجاه الصفحة
    ├── services/
    │   ├── api.js              # عميل Axios للاتصال بالـ Backend API
    │   └── realtimeClient.js   # عميل إدارة اتصال بث التنبيهات الفوري SSE

        ├── Dashboard.jsx       # شاشة المراقبة المركزية ومصفوفة الكاميرات

        ├── Replay.jsx          # عارض الفيديو الجنائي وشجرة القرارات
        ├── Settings.jsx        # ضبط حساسية الذكاء الاصطناعي والكاميرات
        ├── Upload.jsx          # رفع مقاطع الفيديو للتحليل الأمني
        ├── Health.jsx          # مراقبة صحة الخوادم، المعالج، والذاكرة
        └── Confidence.jsx      # إحصائيات دقة النماذج ونسب التحقق
```

## 5. الصفحات التشغيلية والوظائف الأمنية

1. **لوحة التحكم (Dashboard.jsx)**:
   - مصفوفة كاميرات المراقبة الحية (شبكية، رباعية، أو كاميرا واحدة مكبرة).
   - بطاقة التنبيهات الحرجة اللحظية مع وميض بصري وصوت تنبيه تحذيري عند وقوع عنف أو اصطدام.
   - إحصائيات سريعة: الكاميرات النشطة، أحداث اليوم، والقضايا المفتوحة.
2. **سجل الأحداث (Events.jsx)**:
   - جدول تفصيلي يعرض كل حدث، التوقيت، الكاميرا، نوع الحادث، مؤشر الخطورة، والصورة المصغرة.
   - إمكانية تصفية الأحداث حسب النوع أو الكاميرا، وربط الحدث بقضية جنائية وتصدير السجلات إلى CSV.
3. **الإعادة الجنائية وشجرة التفسير (Replay.jsx)**:
   - مشغل فيديو دقيق يتيح القفز بالثواني إلى لحظة الحدث.
   - شجرة تفسير قرارات الذكاء الاصطناعي (Explainability Tree) التي توضح للمحقق: لماذا اعتبر الذكاء الاصطناعي هذا الحدث عنفاً؟ (السرعة المقاسة، مسافة التقارب، ونسبة التحقق ثلاثي الأبعاد).
4. **الملفات والقضايا (Cases.jsx)**:
   - إنشاء ملفات قضايا أمنية رسمية، تعيين المحقق المسؤول، تدوين الملاحظات الجنائية، وأرشفة الأدلة المرتبطة.

## 7. أسئلة المناقشة الأكاديمية الخاصة بالـ Frontend

### س1: كيف تتلقى الواجهة الأمامية التنبيهات الأمنية فور وقوعها دون تأخير؟
**الإجابة النموذجية**:
- عبر تقنية **Server-Sent Events (SSE)** المدارة في `realtimeClient.js` عبر المسار `/api/alerts/stream`. تفتح الواجهة قناة اتصال مستمرة (Persistent HTTP Connection)، ويقوم الخادم بدفع كائن الحدث فور صدوره من الذكاء الاصطناعي، مما يوفر استجابة فورية تقل عن 100 ميلي ثانية، ويقلل استهلاك موارد المعالج مقارنة بأسلوب الـ Polling الدوري.

### س2: كيف تم حل مشكلة توجيه النصوص واللغة بين العربية والإنجليزية في الواجهة؟
**الإجابة النموذجية**:
- عبر `LanguageContext.jsx` الذي يدير حالة اللغة الحالية واتجاه الصفحة `dir="rtl"` للعربية و `dir="ltr"` للإنجليزية، مع تطبيق فئات TailwindCSS المشروطة التي تعكس هوامش العناصر ومحاذاة الأيقونات ديناميكياً دون الحاجة لتكرار الشيفرة البرمجية.
